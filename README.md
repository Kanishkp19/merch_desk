# merch_desk

MerchDesk is a Next.js application for planning creator merchandise collections and launches.

## Local setup

1. Install dependencies with `npm install`.
2. Copy `.env.example` to `.env` and configure any optional provider keys.
3. Run `npm run db:generate` and `npm run db:push` to prepare the local SQLite database.
4. Run `npm run dev` and open http://localhost:3000.

Environment files and local databases are excluded from Git.
